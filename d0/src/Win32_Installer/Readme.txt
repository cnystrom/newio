 
To build the Windows installer binary. 
 
Get http://www.jrsoftware.org/isdl.php and install in Windows. 
 
After you build the binary with 2005 Express, it's in the ./Release directory,
copy to ./install.  cd to ./install and click on the .iss file.  Edit
"AppVerName=Dreadnought Browser version 0.11 "  to whatever build and
then press build->compile.  The ./output directory has setup.exe .  Rename
to d0-0.11_build...
